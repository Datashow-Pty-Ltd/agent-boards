# Support

Agent Boards is an alpha release maintained by Datashow Pty Ltd.

- Use GitHub Issues for reproducible bugs and focused feature requests.
- Use GitHub Discussions for usage questions and design discussion.
- Use GitHub private vulnerability reporting for suspected security issues; do
  not disclose them in a public issue.

The alpha release supports trusted local or self-hosted use only. Public
Internet deployment and authenticated multi-tenant operation are not supported.
